## Project Overview

This project demonstrates the deployment and management of a highly available web application using AWS Cloud Services and Linux.

The project focuses on AWS infrastructure, networking, security, server management, load balancing, monitoring and automation.

## Technologies Used

- AWS Cloud
- Linux
- Git
- GitHub
- Nginx
